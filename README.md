# Petrel

Downloads of Petrel, a native, private mail app for Mac and Windows.

**Mac:** https://petrelmail.com/download · **Windows:** https://petrelmail.com/download/windows · **Website:** https://petrelmail.com · **Privacy:** https://petrelmail.com/privacy

- Mac: macOS 14 or later, Apple silicon or Intel. Signed with Developer ID and notarized by Apple.
- Windows: Windows 10 or 11, 64-bit. Not yet code-signed, so SmartScreen may ask you to confirm.

Petrel is closed source; this repository holds release files only.
