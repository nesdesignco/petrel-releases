# Petrel for Mac

Downloads of Petrel, a native, private mail app for macOS.

**Download:** https://petrelmail.com/download · **Website:** https://petrelmail.com · **Privacy:** https://petrelmail.com/privacy

Requires macOS 26 on a Mac with Apple silicon. Builds are signed with Developer ID and notarized by Apple.
Petrel is closed source; this repository holds release files only.
